# insta-auto-dm

أي شخص يعلّق بكلمة معيّنة على بوستك يوصله مسج تلقائي على الدايركت. مجاني وبالـ API الرسمي من Meta.

---

## 1) تعديل الكلمات والرسائل

افتح `rules.js` وغيّر الكلمات والرسائل مثل ما تريد. كل قاعدة بيها:
- `keywords`: الكلمات اللي تشغّل الرسالة (يتجاهل التشكيل والهمزات والإيموجي).
- `message`: الرسالة اللي توصل على الخاص.
- `publicReply`: رد علني تحت التعليق (اختياري، امسحه إذا ما تريده).
- `mediaIds`: إذا تريدها على بوست معيّن بس. إذا خليتها فارغة تشتغل على كل البوستات.

## 2) جهّز حسابك

1. حوّل حسابك لاحترافي: الإعدادات ← نوع الحساب ← منشئ محتوى أو تجاري.
2. فعّل الوصول للرسائل: الإعدادات ← الرسائل والردود على القصص ← عناصر التحكم بالرسائل ← الأدوات المتصلة ← **السماح بالوصول إلى الرسائل**.

## 3) سوّي تطبيق على Meta

1. ادخل [developers.facebook.com](https://developers.facebook.com) وسجّل كمطوّر.
2. My Apps ← Create App، واختار نوع **Business**.
3. اختار حالة الاستخدام **إدارة المراسلة والمحتوى على Instagram**، واربط حافظة أعمال.
4. حالات الاستخدام ← تخصيص ← **API setup with Unified login**:
   - **إنشاء تكوين جديد** (من القالب).
   - **إضافة حساب** واقبل دعوة المختبِر من انستغرام (الإعدادات ← التطبيقات والمواقع ← Tester Invites).
   - **إنشاء رمز**، هذا يصير `IG_ACCESS_TOKEN` (ما ينتهي). ورقم الحساب يمّه هو `IG_USER_ID`.
5. إعدادات التطبيق ← أساسي ← **المفتاح السري للتطبيق**، هذا يصير `APP_SECRET`.

## 4) ارفع السيرفر (مجاناً على Render)

1. ارفع المجلد على مستودع GitHub (لا ترفع ملف `.env` أبداً).
2. بـ [render.com](https://render.com) اختار New ← Web Service واربطه بالمستودع.
   - Build command: `npm install`
   - Start command: `npm start`
   - Instance type: **Free**
3. بقسم Environment أضف المتغيرات الموجودة بـ `.env.example`. لـ `VERIFY_TOKEN` اختار أي كلمة سر تريدها.
4. بعد الرفع راح يطلعلك رابط مثل `https://insta-auto-dm.onrender.com`. افتحه، إذا كتبلك "شغّال ✅" يعني تمام.

> ملاحظة: النسخة المجانية من Render "تنام" بعد ربع ساعة بلا استخدام، وأول تعليق يصحّيها خلال حوالي دقيقة. فأول رسالة ممكن تتأخر شوية، والباقي يوصل فوراً. Meta تعيد إرسال الإشعار إذا ما وصل.

## 5) اربط الـ Webhook

1. بنفس صفحة API setup with Unified login ← **3. تكوين Webhooks**:
   - Callback URL: `https://رابطك.onrender.com/webhook`
   - Verify token: نفس `VERIFY_TOKEN` اللي حطيته.
2. اضغط Verify and save.
3. اشترك بحقل **comments**.
4. بقسم **2. إنشاء رموز الوصول** فعّل زر **اشتراك Webhook** يم حسابك.
5. إذا ما وصلت الإشعارات، حوّل التطبيق لوضع **Live** من أعلى اللوحة. يحتاج رابط سياسة خصوصية، وتكدر تسويه بأي موقع مجاني.

## 6) جرّب

من حساب ثاني علّق بالكلمة على بوستك. لازم توصل الرسالة، وتشوف بسجلات Render سطر "انرسلت الرسالة الخاصة".

---

## أشياء مهمة

- التوكن من نوع "رمز مستخدم النظام" وما ينتهي. إذا حذفته أو غيرت الصلاحيات، طلّع واحد جديد وحطه بـ Render.
- قيود Meta: رسالة وحدة بس لكل تعليق، وخلال 7 أيام من وقت التعليق.
- تعليقاتك انت ما يرد عليها.
- تجربة محلية بدون انستا: `npm install` وبعدها `npm test`.
